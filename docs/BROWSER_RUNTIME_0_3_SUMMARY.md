# UN_Orion browser runtime 0.3

- UN_Vela 0.3 + Aster 0.3 embedded runtime
- lightweight CSS and safe JavaScript subsets
- BMP/PPM image resource path and framebuffer renderer
- Back / Forward / Reload / Go controls
- clickable links and relative URL handling
- IntelliMouse wheel scrolling with 3-byte PS/2 fallback
- Orion-native HTTP/resources carrier
- HTTPS remains capability-gated until a trusted freestanding TLS provider exists

Hosted UN_Vela builds provide verified HTTPS on Windows, Linux and macOS.
